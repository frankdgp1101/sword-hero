# 剑仙之道 · v4.4 · 第一章

第一人称手机触屏剑仙动作游戏（three.js r160，纯静态网页，横屏游玩）。

在线游玩：https://frankdgp1101.github.io/sword-hero/

## 流程
0. **开场**：黑屏三段旁白（三千万年前混沌初开的异兽、两千万年后两位强者建立“仙境”、五百万年前天降一剑“太初”引发大战），可点击加速或「跳过」。
1. **序章 · 云海问剑**（教程）：你是 **仙尊**（Lv90），迎战魔神，按引导学习移动、普攻、斩马、飞剑、格挡、饮酒与五大神通。可点右上角「跳过教程」。学完普攻、斩马、飞剑、格挡后，魔神喝道「仙尊，就凭这点本事？……且看本尊法相！」，身后升起数倍于他的半透明魔神法相（双角、紫焰、同步他的一招一式），天色由白转为淡紫。
2. 仙尊陨落 → 输入你的剑修之名 → 进入 **第一章 · 学院**（Lv1，御剑尚未习得）。

## v4.4 · 七印镜殿 + 地图 + 第三日自由活动
- **第三日 = 自由活动**：目标改为「在学院中闲逛，准备好后前往居所休息」。10 张书页是 **可选收集品**：没有箭头，不算目标，每张仍是气血上限 +10，会弹出阅读面板，并写入存档。收集进度只在地图面板里显示（书页 n/10）。
- **支线任务接口**：`NPC_QUESTS`（见 09c 注释）。在可接任务的阶段与 NPC「交谈」即可接取。任务步骤支持 到达 / 交谈 / 条件，完成后发奖励，完成记录写入存档。目前只有第三日开放，还没有放入正式任务。
- **魔修圣书**：在密室读完圣书后，点「收集」把书带走（书架上的书随之消失，背包物品写入存档）。不收集就不会触发魔修虚影战。
- **七印镜殿**（取代旧洞窟）：
  - 坠落后与林清风一同醒来，跟随紫色光点穿过地底甬道，来到刻有 **七枚封印** 的巨门前。
  - 点「开启」：七印依次亮起 → 门缝透光 → 门扇滑开，露出约 16 米宽的大台阶。
  - 走下台阶进入椭圆大殿（约 92×64 米，穹顶约 30 米高，16 根石柱，紫色灯火）。殿心是符文圆盘和书架，四周立着 7 面巨镜。
  - 「放置」圣书：圆盘符文亮起，7 面镜子中有 3 面点亮（今印已松其三）。
  - 紫光晶石出现 →「吸收」→ 传送阵 →「传送」，回到图书馆紫门外。
- **地图**（右上角「地图」按钮，键盘 M）：打开时游戏暂停。
  - 学院层：示意图，含各设施名称和玩家位置/朝向。「传送学院 · 山门」只能在学院内、有当前目标、且不在战斗/对话/剧情中时使用，否则显示原因。大比、颁奖、谈心等剧情段落会锁定。
  - 地宫层：显示地宫与七印镜殿示意图。在地宫中不能用地图传送。经镜殿传送阵回到地面后，镜殿解锁「传送点」，可从学院传送到镜殿传送阵旁，阵法可送回图书馆紫门外。解锁状态写入存档。
- 新存档点：甬道 / 七印之门 / 七印镜殿 / 归书之后。旧存档中的「洞窟」会从甬道继续。

## v4.3 · 地宫机关 + 第一章扩充 + 学院扩建
- **学院扩建**：围墙扩大到约 133×133 米。山门挂牌匾「天剑学院」，两名 **守门弟子** 站岗；中央 **大广场** 立着测灵石；西侧 **大钟楼**（约 15 米高，地标）。新建 **药房**（药柜、药罐、柜台、晾药架，药师坐堂）、**食堂**（两条长桌和长凳、灶台大锅，伙夫掌勺）、**弟子居所**。设施 NPC 可以「交谈」，会说一两句闲话或传说。所有建筑都有碰撞，道路宽阔，静态几何已合并。
- **测灵根**：师傅带你到大广场测灵石前。触碰后石头泛起紫光、升起光柱，围观弟子窃窃私语，师傅却语焉不详。
- **三日修行**：
  - 第一日：对 **黑甲陪练** 用斩马命中 ×5，再退到 6 米外用飞剑命中 ×5。
  - 第二日：与林清风切磋，胜负都能继续，台词不同。
  - 第三日：自由活动（v4.4 起书页为可选收集）。之后回弟子居所歇息。
  - 第三日夜：夜景（月亮、灯笼）。在图书馆旁撞见 **墨寒**，与他交谈。
- **大比后**：凉亭 **谈心**（林清风），然后才进入图书馆禁阁。
- **地宫机关**：
  - 石门一：用普攻击打圆钮。
  - 断崖大殿：在 30 余米外用飞剑射中对岸圆钮，石桥升起。
  - 桥上：6 名魔修学徒（斩马可把他们击落断崖；玩家坠崖会回到桥头，扣 12% 气血）。
  - 石门二后是 **紫色屏障**，须施展【隐身】才能通过。
- **魔修虚影**：气血低于 50% 进入第二形态（体型 ×1.45，伤害 ×1.2，速度 ×1.3，新增落剑雨）。打到 10% 时剧情接管：虚影击地，你坠入地底（v4.4：七印镜殿）。
- **御剑试炼**：习得御剑后，御剑穿过学院上空 6 个光环。
- **尾声**：地宫深处，墨寒手握紫色碎片：「第一印……」→ 第一章 结束。

## 第一章 · 天剑学院（v4 新内容）
- **学院场景**：山门、主道石灯、溪流与小桥、两座荷花池、凉亭、学堂（可进入，有课桌蒲团）、图书馆（书架过道、诵经台、尽头暗门）、练武场（比武台、兵器架、战鼓），樱花与松树、远山云海、飘落花瓣。所有建筑与道具均有碰撞，不会穿墙或卡住。
- **人物**：师傅 **青玄真人**（白发长须、手持拂尘）、师兄 **林清风**（青衣马尾，背负细剑，会跟随你，你御剑时他也踩剑同行）、魔派首席 **墨寒**（黑紫长袍、宽刃黑剑）、重剑堂弟子、暗器堂弟子、魔修虚影。人物头顶显示名字；对话框带打字机效果，可点击继续。
- **剧情**：师傅迎接 → 前往学堂（墨寒挑衅、林清风解围）→ 三日后学院大比：
  - 第一场 重剑弟子（大范围砸地、横扫、冲锋，硬直窗口长）→ 升至 Lv2
  - 第二场 暗器弟子（保持距离、连发飞镖、烟雾后空翻）→ Lv3
  - 决赛 墨寒（突进三连斩、剑气、瞬移背刺、爆发）→ Lv5
  - 颁奖 → 师傅带你进图书馆禁阁 → 在诵经台读《无影诀》**习得【隐身】** → 隐身状态下才能看见并进入尽头的紫光暗门 → **地宫** → 阅读魔修圣书（太初之秘）→ 与林清风并肩迎战 **魔修虚影**（他会助战，气血不足时暂退调息）
  - 返回地面向师傅禀报：「师傅，弟子有些事……必须亲自去做。」→ 师傅传授 **御剑之术**（习得【御剑】，御剑按钮解锁，并提示试飞一次）→「去吧。只是记住，御剑先御心，剑有灵，人亦有心。」→ 前往学院大门（可御剑）→ **第一章 结束**
- **目标指引**：左上目标栏（文字 + 方向箭头 + 距离）、场景中金色光柱、屏幕边缘箭头；靠近可交互物时出现「查看 / 进入 / 返回地面」按钮。
- **战斗**：每场比武有红色地面预警、韧性与破防；阵亡后自动从本场重新开始。比武时不能离开比武台。
- **存档**：每个剧情节点自动存档（关卡、等级、已习得神通、御剑是否解锁），标题页「继续游戏」从上次的节点继续。

## v3 内容（保留）
- **多存档**：最多 8 个存档并存（每个剑修一个名字，名字不可重复），同一台手机可多人游玩。输入剑修之名后创建新存档；胜利/升级时只写入当前存档。标题页「继续游戏」打开存档列表（名字、等级、关卡、最近游玩时间，可进入或删除），「新建存档」从序章教程开始（可跳过）。会记住上次使用的存档。旧版单存档会自动迁移。
- **触屏稳定性**：摇杆、滑动转视角、长按普攻均按触点 identifier 追踪，任何 touchend / touchcancel、触点丢失、切后台、失焦、旋转屏幕或弹出菜单时都会自动复位，修复 iPhone Safari 上摇杆卡住、角色持续后退的问题。
- **韧性**：首领血条下方为韧性条（狰 600，魔神 300），不会因脱战自动恢复。韧性越高受伤越低（满 20% → 将空 85%）；削空即「破防」——首领硬直随机 7–10 秒（韧性条显示倒计时），期间受 100% 伤害；硬直结束后韧性在 5 秒内回满（回满期间无法削韧，伤害随当前韧性变化）。斩马削韧最强，格挡弹反次之。
- **弹反**：格挡住近身攻击会反击、大幅削韧并令对手硬直。
- **神通调整**：隐身 3 秒、现身首击「破隐一击」伤害翻倍；护盾 = 20% 气血上限；大河之剑击飞目标并震退周围小怪（首领不位移）；剑雨可按住拖动瞄准落点并减速敌人。
- **御剑撞击**：御剑时撞到敌人造成伤害并击退（首领则把你弹开）。
- **飞剑**往返不到 1 秒。

## 操作（触屏）
- 左下 **摇杆**：移动；右半屏 **滑动**：转动视角
- 摇杆上方 **酒葫芦**：饮酒，每口恢复 15% 气血上限（初始 2 口；每击杀一只怪物补 1 口，不超过上限）
- 右下：**普攻**、**斩马**（横扫）、**飞剑**（飞出并返回）、**格挡**（剑横胸前，0.5 秒内挡下一次攻击；挡住近身攻击触发弹反）
- 底部中央：**御剑**（踩剑高速飞行；第一章结尾由师傅传授后解锁）
- 靠近可交互物时：**查看 / 进入 / 收集 / 放置** 按钮；对话时点击屏幕继续
- 右上 **地图**：学院 / 地宫示意图与传送
- 左侧 **神通**（十字五键）：中 **大河之剑**、上 **万剑归宗**、左 **剑雨**（按住拖动瞄准）、右 **隐身**、下 **护盾**
- 气血：初始 1000，每升一级 +50
