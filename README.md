# 剑仙之道 · v2

第一人称手机触屏剑仙动作游戏（three.js r160，纯静态网页，横屏游玩）。

在线游玩：https://frankdgp1101.github.io/sword-hero/

## 流程
1. **序章 · 云海问剑**：你是诗剑仙 **李白**（Lv90），立于云海之巅，迎战走火入魔的紫衣师兄「剑魔」。按引导依次学习：摇杆移动/滑动视角、普攻、斩马、飞剑、格挡、饮酒，以及五大神通。可点右上角「跳过教程」。
2. 师兄重伤之际一剑击败李白 → 黑屏：「李白剑仙陨落之后，一位普通的剑修将接替他的使命。」→ 输入你的剑修之名（默认「无名剑修」）。
3. **第一战 · 幽谷**：Lv1 剑修（200 气血、2 口酒）在环形山谷中迎战山海异兽「狰」（Lv20，1000 血）。此战神通尚未领悟。狰会扑击、冲撞、爪击、吼出火球——看清红色地面预警，闪避或格挡。胜利后显示「胜利」；阵亡可再次挑战。

## 操作（触屏）
- 左下 **摇杆**：移动；右半屏 **滑动**：转动视角
- 摇杆上方 **酒葫芦**：饮酒，每口恢复 50 气血（初始 2 口；每击杀一只怪物补 1 口，不超过上限）
- 右下：**普攻**、**斩马**（横扫）、**飞剑**（飞出并返回）、**格挡**（剑横胸前，0.5 秒内挡下一次攻击）
- 底部中央：**御剑**（踩剑高速飞行）
- 左侧 **神通**（十字五键）：中 **大河之剑**、上 **万剑归宗**、左 **剑雨**、右 **隐身**、下 **护盾**
- 气血：初始 200，每升一级 +20
