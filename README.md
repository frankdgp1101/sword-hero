# 剑仙之道 · v3

第一人称手机触屏剑仙动作游戏（three.js r160，纯静态网页，横屏游玩）。

在线游玩：https://frankdgp1101.github.io/sword-hero/

## 流程
1. **序章 · 云海问剑**：你是诗剑仙 **李白**（Lv90），立于云海之巅，迎战走火入魔的紫衣师兄「剑魔」。按引导依次学习：摇杆移动/滑动视角、普攻、斩马、飞剑、格挡、饮酒，以及五大神通。可点右上角「跳过教程」。
2. 师兄重伤之际一剑击败李白 → 黑屏：「李白剑仙陨落之后，一位普通的剑修将接替他的使命。」→ 输入你的剑修之名（默认「无名剑修」）。
3. **第一战 · 幽谷**（测试关）：Lv1 剑修（1000 气血、2 口酒）在环形山谷中迎战山海异兽「狰」（Lv20，8000 血，带韧性条）。此战神通尚未领悟。狰会扑击、冲撞、爪击、吼出火球——看清红色地面预警，闪避或格挡弹反。胜利后显示「胜利」；阵亡可再次挑战。

## v3 新内容
- **存档**：输入剑修之名后自动存档（名字、等级、经验、关卡、已领悟神通、酒），胜利/升级时再次存档。标题页有存档时显示「继续游戏」（直接进入幽谷）与「重新开始」（确认后清除存档并从序章开始）。
- **韧性**：首领血条下方为韧性条（上限 200）。韧性满时只受 20% 伤害，越低伤害越高（最高 85%）；削空即「破防」——受 100% 伤害并硬直 2.5 秒，之后 3 秒内韧性回满。斩马削韧最强，格挡弹反次之。
- **弹反**：格挡住近身攻击会反击、大幅削韧并令对手硬直。
- **神通调整**：隐身 3 秒、现身首击「破隐一击」伤害翻倍；护盾 = 20% 气血上限；大河之剑击飞目标并震退周围小怪（首领不位移）；剑雨可按住拖动瞄准落点并减速敌人。
- **御剑撞击**：御剑时撞到敌人造成伤害并击退（首领则把你弹开）。
- **飞剑**往返不到 1 秒。

## 操作（触屏）
- 左下 **摇杆**：移动；右半屏 **滑动**：转动视角
- 摇杆上方 **酒葫芦**：饮酒，每口恢复 15% 气血上限（初始 2 口；每击杀一只怪物补 1 口，不超过上限）
- 右下：**普攻**、**斩马**（横扫）、**飞剑**（飞出并返回）、**格挡**（剑横胸前，0.5 秒内挡下一次攻击；挡住近身攻击触发弹反）
- 底部中央：**御剑**（踩剑高速飞行）
- 左侧 **神通**（十字五键）：中 **大河之剑**、上 **万剑归宗**、左 **剑雨**（按住拖动瞄准）、右 **隐身**、下 **护盾**
- 气血：初始 1000，每升一级 +50
