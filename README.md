# 山海剑侠（第一人称手机触屏剑侠游戏）

- 打开 `index.html`（需和 `three.min.js`、`game.js` 放在同一目录），或直接打开 `index-single.html`（单文件版，什么都内置了，可以直接发到手机上打开）。
- 手机横屏游玩，纯触屏操作，运行时不需要联网（three.js r160 已放在本地）。

## 操作
- 左下摇杆（左侧 45% 区域内按到哪里就从哪里出摇杆）：前进 / 后退 / 左右平移
- 右侧空白处滑动：转动视角（左右转、上下看）
- 右下大按钮：普攻（按住可以连续挥砍）
- 斩马（5 秒冷却）：横向大范围挥斩
- 飞剑（7 秒冷却）：剑脱手向前飞出，穿透敌人后再飞回手中
- 锋芒毕露（16 秒冷却）：剑竖在屏幕中央，巨剑从天而降，砸向目标
- 下方中间的御剑（10 秒，结束后冷却 8 秒，再按一次可以提前结束）：踩剑飞行，速度大幅提升，还能飞过湖面
- 桌面调试：鼠标可以当手指用；也可以用 WASD / 方向键、J 或空格普攻、1/2/3 放技能、R 御剑
